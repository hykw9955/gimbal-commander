# Gimbal Commander (Android)

ジンバル付属のBluetoothリモコンのキーコード・モーションイベントをキャプチャし、Xperiaのカメラ操作（シャッター、ズーム、フォーカスなど）を行うAndroidアプリケーションです。

---

## 主な機能

1. **Bluetoothリモコン キーキャプチャ & 解析（Key Tester）**
   - リモコンのボタンを押すと、`keyCode`, `scanCode`, `deviceName`, `action (DOWN/UP)` をリアルタイム表示。
   - ジョイスティックやスライダーの `MotionEvent`（各Axis値）の検知。
2. **キーマッピング & カメラ操作テスト（Camera Screen）**
   - CameraXを用いたカメラプレビュー。
   - キャプチャしたキーを「シャッター」「ズームイン」「ズームアウト」「オートフォーカス」「カメラ切替」に割り当てて動作検証。
3. **バックグラウンド キー傍受（Accessibility Service）**
   - Xperia標準のカメラアプリ（Photography Pro等）をバックグラウンドからリモコン操作するための `GimbalAccessibilityService` の土台を実装。

## 開発 & 検証の流れ

### 1. リモコンとAndroidスマホのペアリング
1. ジンバルのリモコンをペアリングモードにします。
2. Xperiaの「設定」→「接続済みのデバイス」→「新しいデバイスとペア設定」からリモコンを接続します。

### 2. アプリのビルド・起動
- Android Studioで本プロジェクトを開き、実機（Xperia）にインストールして実行します。

### 3. キーコードの特定（Key Testerタブ）
1. アプリを起動し「キー解析」タブを開きます。
2. ジンバルリモコンの各ボタン（シャッター、ズームレバー、Mボタンなど）を押します。
3. 画面上に表示される `KeyCode`（例: `KEYCODE_VOLUME_UP`, `KEYCODE_CAMERA`, `KEYCODE_MEDIA_PLAY_PAUSE` 等）を確認します。
4. ドロップダウンから行いたいカメラアクション（シャッター、ズーム等）を選択して割り当てます。

### 4. カメラ動作確認（カメラタブ）
1. 「カメラ」タブに切り替えます。
2. 先ほど割り当てたボタンを押して、シャッターが切れるか、ズームが動作するかを確認します。

## Xperia標準カメラアプリを操作したい場合

自前カメラではなくXperia標準の「Photography Pro」やカメラアプリをリモコン操作したい場合は、以下の手順でユーザー補助サービスを有効化します。

1. アプリ右上の「歯車アイコン」をタップ（またはAndroid設定 →「ユーザー補助」へ移動）。
2. 「ダウンロードしたアプリ / インストール済みのサービス」から **Gimbal Commander** を選択して「ON」にする。
3. `GimbalAccessibilityService.kt` 内でキーを監視し、目的のインテントやキーコード（`KEYCODE_CAMERA` など）をトリガーする処理を拡張できます。
